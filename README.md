# FieldCommand: Baseball Defense Planner

A simple, web-based tool for baseball coaches to plan defensive strategies. Drag players, draw plays, and share strategies via URL. Built as a proof-of-concept to gather feedback.

## Live Demo
Try it at: [https://fieldcommand.netlify.app/](https://fieldcommand.netlify.app/)

## Features
- Drag and drop players on a baseball field.
- Draw solid or dotted lines to plan plays (5-minute demo mode).
- Share plays via URL.
- Mobile and desktop friendly.
